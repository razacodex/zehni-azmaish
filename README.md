# ज़हनी आज़माइश — PWA

GitHub Pages-ready Progressive Web App.

## Files
- `index.html` — original app with PWA integration
- `manifest.json` — install metadata
- `service-worker.js` — offline app-shell caching
- `icon-192.png` / `icon-512.png` — PWA icons

## GitHub Pages
Repository name: `zehni-azmaish`

Upload all four files plus the two icons to the repository root, then enable:
Settings → Pages → Deploy from branch → `main` → `/ (root)`

The app must be served over HTTPS (GitHub Pages provides HTTPS).
